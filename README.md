# Object Detection using TensorFlow

## Setup Instructions

1. Install TensorFlow Object Detection API (follow official GitHub).
2. Prepare your dataset in `data/images/` with bounding box annotations.
3. Run `data_preparation.py` to split data.
4. Train your model using TensorFlow Object Detection scripts.
5. Run inference using `inference.py`.

> This is a basic project scaffold. Integrate your data and model configs for full functionality.
